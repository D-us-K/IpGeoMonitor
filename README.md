# IP 地理监控（IpGeoMonitor）

一个悬浮在桌面上的 **小通知条**，实时显示本机公网 IP 和它所在的国家/地区。

- **零依赖**：只用 Windows 11 自带的 PowerShell 5.1 + .NET Framework，不需要安装 Python、Node 或任何运行库。
- **双击即用**：双击 `IP地理监控.exe`（或桌面上的「IP 地理监控」快捷方式）即可，不留黑窗口。
- **不占地方**：默认 336×63 像素，圆角、可调透明度、可拖动、可总在最前。

---

## 一、快速开始

双击 **`IP地理监控.exe`**（桌面上已创建同名快捷方式），通知条会出现在桌面右上角。

> 也可以双击 `启动监控.vbs`，效果相同；`启动监控-调试窗口.cmd` 会保留控制台便于看错误输出。

| 想做什么 | 怎么做 |
| --- | --- |
| 立即刷新 | **左键单击**通知条任意位置，或点右侧的 ↻ |
| 打开菜单 | **右键单击**通知条 |
| 打开设置 | 右键 → **设置…**（或双击通知条，默认行为可改） |
| 移动位置 | 按住左键**拖动** |
| 临时隐藏 | 右键 → **隐藏到托盘**（双击托盘图标可恢复） |
| 完全退出 | 右键 → **退出**（或托盘图标右键 → 退出） |
| 看详细信息 | **鼠标悬停**：IP、国家、城市、运营商、时区、数据源、耗时、更新时间全在里面 |

不点它的话，默认**每 60 秒自动刷新一次**（右下角有倒计时）。

## 二、界面说明

```
┌──────────────────────────────────────────┐
│  ⬤HK   中国香港                     ↻    │   ← 徽标 + 国家/地区 + 刷新按钮
│        183.192.10.136               45s  │   ← IP 地址 + 下次刷新倒计时
│        上海市 · 上海 · 中国移动            │   ← 城市/运营商（可选显示）
└──────────────────────────────────────────┘
```

- 左侧 **⬤HK** 是按国家代码生成的彩色徽标；也可以在设置里换成 Emoji 旗帜或关掉。
- 倒计时正常是灰色，查询中变成蓝色转圈，**失败会变红显示"失败"**（此时仍显示上一次成功的结果，不会变空）。

## 三、右键菜单有什么

- **立即刷新 (F5)** / **复制 IP 地址** / **复制完整信息** / **搜索该 IP 归属**
- **显示内容**：国家、IP、城市、运营商、倒计时、更新时间、徽标样式（3 选 1）
- **刷新间隔**：30 秒 / 1 分钟 / 2 分钟 / 5 分钟 / 15 分钟 / 30 分钟 / 自定义
- **数据源**：自动检测 / ip-api.com / ipwho.is / ipinfo.io / zxinc.org / ip.sb / ip.3322.net
- **窗口**：总在最前、锁定位置、贴边吸附、鼠标穿透、尺寸（小/中/大）、不透明度、主题（深色/浅色）
- **设置…**、**开机自动启动**、**隐藏到托盘**、**退出**

## 四、设置窗口有什么

| 分组 | 选项 |
| --- | --- |
| **刷新** | 刷新间隔（10–3600 秒）、请求超时（3–60 秒）、启动后立即刷新、失败时自动换其他方式重试 |
| **数据源 / 网络** | 优先数据源、自定义 URL、网络方式（跟随系统代理 / 直连 / 自定义代理）、代理地址 |
| **显示内容** | 国家、IP、城市、运营商、倒计时、更新时间、徽标样式、国家名语言（中文/英文）、双击行为、主题 |
| **窗口** | 尺寸、总在最前、锁定位置、贴边吸附、记住位置、鼠标穿透、不透明度、字体缩放、开机自动启动 |

底部还有 **测试连接**（立刻验证当前数据源和网络能不能通）、**恢复默认**、**取消**、**保存并应用**。
保存后立即生效，不需要重启程序。

## 五、数据源说明（为什么默认走 HTTP）

免费且稳定的公网 IP 归属地接口里，**ip-api.com 的免费版只提供 HTTP**（HTTPS 要付费），所以默认数据源是 `http://ip-api.com`。
程序内置了 7 个数据源，默认"自动检测"：**按顺序试，谁先成功用谁**，全部失败才报错。所以某个站点挂了或被墙了也不会影响使用。

查询结果只包含"这个公网 IP 属于哪个国家/城市/运营商"，不会上传你本机的任何其他信息。

## 六、文件与配置位置

| 文件 | 说明 |
| --- | --- |
| `IP地理监控.exe` | **双击启动器（推荐）**，4.5 KB 原生小程序，无控制台窗口 |
| `IpGeoMonitor.ps1` | 主程序（全部逻辑，UTF-8 with BOM） |
| `启动监控.vbs` | 备用的静默启动器，效果与 exe 相同 |
| `启动监控-调试窗口.cmd` | 带控制台启动，程序出错时会显示输出，排错用 |
| `界面预览.png` | 通知条实际效果截图（336×63） |
| `README.md` | 本文档 |

桌面快捷方式「IP 地理监控」指向 `IP地理监控.exe`，可一键启动；不需要时直接删掉该快捷方式即可。

运行数据（配置、缓存、日志）默认保存在：

```
%APPDATA%\IpGeoMonitor\
    config.json     设置
    last.json       上次成功的查询结果（启动时先显示，避免空白）
    monitor.log     运行日志（自动截断，不会无限增长）
    launch.vbs      开机自启用的启动器（开启自启后才生成）
```

如果该目录不可写（比如受限环境），会自动退回到程序目录下的 `data\`，再不行用临时目录。

## 七、开机自动启动

右键菜单勾选 **开机自动启动**，或设置窗口里勾选，会在**当前用户的启动文件夹**里创建一个快捷方式：

```
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\IP地理监控.lnk
```

取消勾选会自动删除它。不需要管理员权限，也不写注册表。

## 八、常见问题

**1）显示"失败"怎么办？**
鼠标悬停查看具体错误；或右键 → 设置 → 点 **测试连接**。多数情况是网络/代理问题：
- 公司网络或代理软件可能拦截了这些接口，试试把"网络方式"改成 **直连** 或 **跟随系统**；
- 如果本机开了全局代理但代理没启动，会出现全部接口请求失败，关掉系统代理或改直连即可；
- 换个数据源（比如 ip.sb 只返回 IP，程序会自动再查一次归属地）。

**2）IP 显示的和我想的不一样？**
程序显示的是**本机对外访问时的公网 IP**。如果开了代理/VPN，看到的就是代理出口的 IP——这正是"实时监控 IP 地理位置"的用途。

**3）国家名显示成英文？**
部分接口（ipwho.is / ipinfo.io）本身只返回英文。设置里把"国家名语言"设为**中文**，程序会用内置的 250+ 国家代码表翻译成中文；设为英文则保持原样。

**4）任务栏里没有图标？**
正常现象，程序刻意不显示任务栏按钮（避免占位），只在**通知区域（托盘）**显示图标，双击可显示/隐藏通知条。

**5）开了"鼠标穿透"后点不到它了？**
鼠标穿透会让通知条完全不吃鼠标事件（方便贴在其他窗口上）。从**托盘图标右键 → 取消鼠标穿透**即可恢复。

## 十、技术说明

- **技术栈**：PowerShell 5.1 + WinForms（`System.Windows.Forms`），主窗口是自绘的圆角无边框窗口，通过 `Region` 裁圆角、`Form.Opacity` 调透明度。
- **不卡界面**：网络查询跑在独立的后台 Runspace 里，界面用定时器轮询结果，所以超时等待期间窗口照样能拖动、点击、右键。
- **网络兼容**：同时支持系统代理 / 直连 / 自定义代理，失败自动切换；TLS 1.2/1.3 已显式开启；HTTP 与 HTTPS 接口都能解析。
- **健壮性**：单实例互斥锁（不会重复启动多个）；失败保留上次结果；配置写坏不会导致启动失败（会回退默认值）；所有界面事件处理器的异常都会写入 `monitor.log`（PowerShell 默认会静默吞掉事件处理器里的错误，这是排查界面问题的关键）。
- 因为主程序是 `.ps1`，请**不要用记事本另存**它——必须保持 **UTF-8 with BOM** 编码，否则 PowerShell 5.1 会按 GBK 读取导致中文乱码和语法错误。

### 修改源码时的两个 PowerShell 陷阱

1. **事件处理器拿不到函数局部变量**。`$btn.Add_Click({ $btn.Text })` 这种写法在函数内部创建时会失效（PowerShell 脚本块不形成闭包），必须用脚本作用域变量（`$script:xxx`）。本程序在设置窗口里用"把控件引用提升到脚本作用域"的方式统一处理。
2. **逗号运算符的优先级高于 `+`/`-`**（与多数语言相反），所以

   ```powershell
   New-Object System.Drawing.RectangleF($r.X + $n, $r.Y + $n, ...)   # 会报 op_Addition 错误
   ```

   会被解析成"先逗号分组、再相加"，结果是 `Object[] + 值`。请改用不受影响的写法：

   ```powershell
   [System.Drawing.RectangleF]::new($x, $y, $w, $h)                  # 正确
   ```

## 十一、卸载

1. 右键通知条 → **退出**；
2. 取消勾选"开机自动启动"（或直接删掉启动文件夹里的 `IP地理监控.lnk`）；
3. 删除 `%APPDATA%\IpGeoMonitor\` 和程序目录即可，不留残余。
